# Syndic App 🏠
Application de gestion de syndic développée en Python + SQLite + Tkinter.

## 🎯 Objectif
Gérer les copropriétaires, paiements, dépenses, réclamations et rappels dans une interface simple et intuitive.

## 🧩 Structure du projet
- **db.py** : moteur SQL (connexion, création des tables, fonctions CRUD)
- **ui.py** : interface graphique (Tkinter)
- **main.py** : point d’entrée (initialisation + lancement)
- **syndic.db** : base SQLite générée automatiquement
